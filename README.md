# 📝 Quiz App

A simple and interactive **Quiz Application** built using **HTML, JavaScript, and Bootstrap 5**. This project displays multiple-choice questions, allows users to navigate through them, includes a countdown timer, and displays the final score after quiz completion.

## ⚙️ How It Works

1. Open the Quiz App.
2. Read the displayed question.
3. Select the correct option.
4. Click the **Next Question** button.
5. Repeat until all questions are completed.
6. View your final score.
